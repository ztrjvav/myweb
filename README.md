# JVAV · Music × Code Studio

GitHub Pages 门户网站，用来介绍 JVAV 并引导访客访问正式主站。

- **主站：** [https://jvav.cc/](https://jvav.cc/)
- **GitHub Pages：** [https://ztrjvav.github.io/myweb/](https://ztrjvav.github.io/myweb/)
- **源代码：** `index.html`（原生 HTML + CSS，响应式设计，不依赖构建流程）

## 维护说明

修改 `index.html` 即可更新门户的布局、文字与链接。网站目前作为主站的独立入口，不会自动同步 jvav.cc 的视觉样式或内容。若主站设计有更新，需要单独调整本仓库。
